# 新增片源與投放修正（2026-09-23）

- 新增劇集來源接上伺服器換集／連播；明確選集優先，其次伺服器觀看紀錄，最後來源預設第一集。歷史秒數只套用同一集。
- API 新增 resolved_episode_id、Tag.browsable、Listing.notice，保留既有路徑與欄位。
- Gimy 備援最多三條候選，解析請求共用 45 秒上限；來源拒絕或限流不立即加發請求。
- 搜尋遭拒時只使用已載入片單備援並提示範圍；沒有快取就顯示錯誤。相同查詢合併，成功結果短暫快取，搜尋冷卻不阻擋播放。分頁只跟隨來源實際連結。
- 修正 CDN 根網域邊界；成功讀取動態 CDN 媒體延長 60 分鐘閒置期限；網頁與 LG 子清單使用同一驗證。
- 403、429、503 保留上游狀態；只有 Retry-After 存在時顯示來源建議等待時間。
- 無可瀏覽頁面的標籤改為純文字。
